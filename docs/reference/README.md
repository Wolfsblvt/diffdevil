## Meaning

This is the durable public map of diffdevil's founding research, alternatives,
implementation advice, and returned qualification evidence. It preserves why the
product has its shape without requiring private conversations or treating an old
return as today's manual. Public editions remove personal/session instructions,
not technical capability or meaningful unsuccessful observations.

## Provenance and preservation

The public-edition pass is dated September 15, 2026. Unique original conversations, branding input, implementation returns and private
source variants are preserved separately from public Git. The earlier full
development return retains pre-publication Git history; it is not included again
as a nested backup of the active checkout. Those originals
include personal instructions and local operational coordinates, so they are not
part of public Git ancestry. The selected technical editions here are explicitly
not byte-identical transcripts.

Technical editions do not discard the underlying original meaning. Exact duplicate
private records may share one archived copy; current public references have one
canonical location rather than an attachment mirror. No unrecovered implementation is
counted as present. Historical local artifact paths are evidence coordinates, not
promises that a public reader can fetch a private runtime log. Current executable
contracts supersede old syntax; a historical qualification result never qualifies
subsequently changed bytes.
