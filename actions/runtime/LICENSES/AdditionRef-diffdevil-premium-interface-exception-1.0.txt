0. Definitions

"The Program" means the files licensed under AGPLv3 with this permission, and
any modification of them.

"The Premium Service Interface" means the optional `premium` argument of
`createAnalyticalDataService` in `apps/github-app/analytical-data.mjs`: the
extension object supplied through that argument, the host object the Program
provides to compose it, and the calls and data shapes the Program documents
for that exchange.

"The Premium Application Interface" means the optional extension the App
build resolves from the module specifiers `@diffdevil/premium-app` and
`@diffdevil/premium-styles`: the composed extension object and its documented
parts, including its pull-request brief provider, which the managed-App Worker
also resolves from the module specifier `@diffdevil/premium-brief`; the
premium slots of the App's pages that render those parts; and the
registration calls the Program documents for that extension.

"The Declared Interface Files" of a version of the Program are the files that
version lists for each interface in `premiumSeam.interfaces` of
`apps/github-app/release.json`.

"A Published Interface" means the Premium Service Interface or the Premium
Application Interface exactly as it exists, unmodified, in a version of the
Program that Wolfsblvt Works has published as source and that declares it.
A Published Interface consists of that version's Declared Interface Files for
that interface.

"An Independent Module" means a work that:

  (a) is not a copy or modification of the Program, or of any part of it,

  (b) joins the Program only through one or both Published Interfaces, used

  (c) contains, from the Program, only the names, module specifiers, function

Code copied from or derived from the Program does not become an Independent
Module because it is moved into another file, package or repository.

"A Combined Work" means a work, in source form, in object form or as a
program run for users interacting with it remotely, that consists of the
Program combined with one or more Independent Modules through Published
Interfaces.
