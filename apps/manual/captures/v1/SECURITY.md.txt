# diffdevil security reporting

## Meaning

This is the public route for privately reporting a suspected vulnerability in diffdevil. GitHub's private vulnerability reporting is enabled for `Wolfsblvt/diffdevil`; reports go to this repository's administrators for triage. It does not promise a response time or support lifetime that has not been established.

## Report privately

Use the **Report a vulnerability** button on [diffdevil's GitHub security advisories page](https://github.com/Wolfsblvt/diffdevil/security/advisories). Include the affected version or commit, a reproducible description, and the security consequence. Please keep exploit details out of public Issues and pull requests while the report is being assessed.

The current source and the latest published release are the first investigation targets. Older release support, disclosure timing, and fixes are assessed case by case; this file does not promise a standing maintenance window.
