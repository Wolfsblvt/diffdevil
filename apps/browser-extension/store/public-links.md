# Extension public links

## Meaning

This is the extension's publication-time URL map: the prepared destinations in the package, the Store fields, the temporary public fallbacks and the readback that admits each final value. Source configuration is not evidence that a site or contact service is live. The extension, its public notice and its Store entry must describe the same product when submitted.

The package prepares the final product, manual, FAQ, maker and contact links before launch. The local `privacy.html` and `licenses.html` remain available without a website. Public GitHub source and Issues remain useful alongside the future sites. This preparation neither deploys those sites nor changes their source.

Keeping the direct GitHub notice is valid while no replacement has that standing.

## Finite launch readback

After the Works contact and diffdevil site/manual owners return their actual deployments:

1. Open each selected HTTPS destination in a signed-out browser. Record date, final URL, status and visible result; a parking page, generic redirect or HTTP 200 alone is insufficient.
2. Follow the extension page's notice and support links. Compare the public notice with `privacy.md` in the exact source that built the ZIP. Confirm the current site legal result has not changed a product fact the bundled notice needs to carry.
3. Check `product=diffdevil` selection and the explicit return route. Consume the contact operator's delivery/privacy evidence; do not send test mail merely to check a link. Do not mark an additional direct contact provisioned from URL configuration alone.
4. Substitute the final Homepage and Support values in the dashboard packet. Retain the public extension notice above unless an accepted dedicated route has passed step 2. Set Official URL only from the observed verified property.
5. Read back every packaged link once from the installed candidate, including local Privacy and Licences. If any packaged URL or notice changes, rebuild from the accepted source, record the new hash and compare affected members before uploading. A dashboard-only URL change does not rewrite the ZIP.

Record these results with the exact package handoff in `submission.md`'s format. All named site/contact destinations remain publication dependencies until this readback exists; this document does not infer deployment from a configured URL.
