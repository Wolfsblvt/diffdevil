# Source-candidate changes

## 1.0.0 browser source candidate

Added a portable, self-contained MIT browser API over the existing engine, with conservative acquisition, layered real policies, typed aggregate/file presentation and explicit optional App identity standing. Extracted the existing pure GitHub-file normalizer for reuse rather than forking measurements.

Added a Chrome Manifest V3 application with worker analysis, guarded public-source fallback, trusted-base policy acquisition, bounded rebuildable cache and recoverable settings transactions. Added GitHub lifecycle handling, full-PR and lazy per-file measurements, inspectable non-modal reports, dynamic bands, virtual label metadata and explicit native-picker handoff.

Added a complete options application with authored dark/light themes, search, Basic/Advanced discovery, literal stable anchors, icon choices, band/path/YAML and repository-policy editors, validation, per-setting reset, cache management, redacted diagnostics and portable import/export. Unsaved edits survive navigation within settings.

Added core, application, rendered-browser, acquisition and installed-browser qualification paths, candidate evidence receipts, Store listing/submission material and reproducible icon/screenshot/promotion assets. Nothing was merged, deployed or published by the local build.

The canonical centre-seam `diffdevil/brand` glyph is integrated from its pinned accepted MIT source. Authenticated App report delivery remains a separate integration boundary; local results remain explicit. Installed/live/Windows evidence must be accepted separately.
